Payroll Desk PDF loading repair - V9.11.1

CAUSE CONFIRMED ON THE LIVE SITE
The app requests vendor/pdf-lib.min.js and vendor/fontkit.min.js; both return HTTP 404. The uploaded libraries are actually at pdf-lib.min.js and fontkit.min.js in the main site folder. Both deployed files match the tested library copies.

INSTALL
1. Extract this ZIP.
2. Upload and replace these FOUR files in the main folder of the Payroll-desk1 GitHub repository: index.html, w2.html, offer.html, sw.js. Upload the files themselves, not this ZIP or a new enclosing folder.
3. Keep your existing pdf-lib.min.js and fontkit.min.js beside index.html. No library files need to be moved for this patch.
4. Wait for the GitHub Pages deployment to finish. Open the website in Safari, reload, then close and reopen the home-screen app if you use it.
5. Generate a fresh PDF. Check payroll statements, W-2 exports and offers.

This patch changes script paths on the three document pages and refreshes the offline cache identifier and paths. It does not change payroll entries or company profiles. The live website was inspected; this ZIP has not been uploaded to your GitHub repository by the assistant.
