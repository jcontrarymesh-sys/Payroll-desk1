PAYROLL DESK — iPhone paystub creator

Open the app in Safari using a secure HTTPS static web host. To install: Safari > Share > Add to Home Screen.

Free hosting option: GitHub Pages (requires a free GitHub account). Create a public repository, upload all files from this folder at its root, and enable Settings > Pages > Deploy from branch > main / root. Open the published URL in Safari, then Add to Home Screen. Note: repository source code and bundled default sample employee details are public on a public GitHub Pages repository; do not upload real employee data or private documents. Information entered in the app is processed in the browser.

Draft PDFs are visibly marked. Final mode requires a real payment reference and confirmation. The app does not send PDFs automatically. Calculations and accessibility have not been certified for production payroll.

Version 7: comments field; automatic annual pay period number with manual override; editable annual period count.
